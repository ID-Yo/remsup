What do I need to run Remsup?

Windows x64 and the separately installed Evergreen WebView2 Runtime. Build the single Windows EXE from source using the prerequisites in the README. No hosted relay, update service or release executable is supplied with the source snapshot.

Build prerequisites ↗
Does closing the window end support?

No. Closing or minimizing the window can keep support running in the tray. Use Stop support to end receiving support, or tray Exit to close the application.

How does owner consent work?

Work requires device-owner authorization. Screen access follows the receiving device’s settings; automatic approval after pairing can be enabled. Do not assume every command or screen action prompts the owner. Windows administrator elevation remains a local owner action.

Can an operator change Remsup settings?

Remote editing of ordinary settings is OFF by default. It requires local owner opt-in and an authenticated screen-control session, and is limited to specified settings. Permission changes, credentials, firewall and administrator actions remain local.

What should I know about the security model?

Windows relay and LAN connections use TLS with a verified certificate pin. The relay administrator can inspect relayed data; this is not end-to-end encryption. The source snapshot is not production security approval. Review the security documentation and provision your own endpoints.
