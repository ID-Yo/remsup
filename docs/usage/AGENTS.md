# Operator rules

Use only the exact owner-authorized profile and task scope. Load saved credentials through the protected helper; never print or place them in command arguments, prompts or logs. No hostname discovery or identity probe is required. On ambiguous profile/access or unknown command outcome, stop and resolve it; never automatically replay.

See 03-agent-guide.md, 04-troubleshooting.md and the supplied skill. Do not interact with UAC or customer screens beyond explicit authorization.
