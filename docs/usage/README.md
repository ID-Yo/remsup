# Usage

Build one EXE using the root README. Run the visible application. Configure your own verified TLS relay in Settings > Network before receiving or connecting. The reserved defaults intentionally do not resolve to a service. Give an authorized operator the Device ID and current OTP through a protected channel, or explicitly configure a permanent password. Stop support or use tray Exit when access should end.

Screen access is governed by receiving Security settings. Automatic approval after pairing may be enabled; do not assume that every command or screen action prompts the owner. Authorized command access is separate from UAC elevation.

For AI/operator integration, read [the support skill](../../skills/remsup-support/SKILL.md), [agent access](03-agent-guide.md) and [troubleshooting](04-troubleshooting.md). The skill can be installed independently, but it does not grant permission or provision infrastructure.
